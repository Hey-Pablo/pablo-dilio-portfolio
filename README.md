# Portfólio — Pablo Dilio

**Analista de Implantação e Suporte ERP** com experiência em **SQL, dados e desenvolvimento web**.

Atuo do levantamento de requisitos à homologação, conectando regras de negócio, usuários e tecnologia para entregar soluções funcionais. Este repositório contém o código do meu portfólio e uma seleção de projetos com demos públicas e evidências visuais de projetos privados.

🔗 **Portfólio publicado:** [hey-pablo.github.io/pablo-dilio-portfolio](https://hey-pablo.github.io/pablo-dilio-portfolio/)

## Evidências principais

- Implantação, parametrização, treinamento e suporte B2B em sistemas ERP.
- Consultas SQL Server para análise, validação e investigação de dados.
- Projetos web com React, TypeScript, Supabase/PostgreSQL e RLS.
- Interfaces responsivas e interativas com HTML, CSS e JavaScript.
- Documentação de processos, levantamento de requisitos e resolução de problemas.

## Stack e ferramentas

- **Web:** React, TypeScript, JavaScript, HTML5, CSS3, Tailwind CSS
- **Dados:** SQL Server, PostgreSQL, Supabase, Power BI
- **Produto:** levantamento de requisitos, regras de negócio, documentação e UX
- **Operação:** Git/GitHub, GitHub Pages, Hostinger e suporte remoto

## Como executar localmente

```bash
npm install
npm run dev
```

## Verificações de qualidade

```bash
npm run lint
npx tsc --noEmit
npm run build
```

O build gera a pasta `dist/`, pronta para publicação em hospedagem estática.

## Estrutura

```text
src/
├── components/    # Seções e componentes React
├── data/          # Projetos, habilidades, experiência e formação
├── hooks/         # Hooks customizados
├── integrations/  # Integrações do projeto
└── assets/        # Referências visuais dos projetos
```
